# Reference data

`npm run seed:reference` downloads these files and caches them here (they are gitignored):

| File | Source | License |
|---|---|---|
| `airports.csv` | https://davidmegginson.github.io/ourairports-data/airports.csv | Public domain (OurAirports) |
| `airlines.dat` | https://raw.githubusercontent.com/jpatokal/openflights/master/data/airlines.dat | ODbL 1.0 (OpenFlights) |

If the download fails (offline, firewall), place the files here manually with those names
(`airlines.csv` is also accepted) and re-run the seed.
